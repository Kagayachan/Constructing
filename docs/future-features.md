# 未来可能添加的功能

> 候选能力清单。首版（v1.0.0）**不包含**下列项。  
> 排序仅表示建议优先级，不代表承诺时间表。  
> 部分条目摘自需求文档 §24，并补充了实现期观察到的缺口。

## P1：视觉与转换质量（建议优先）

对应需求文档里程碑 M5 / §20.2。

| 功能 | 说明 | 动机 |
|---|---|---|
| 颜色提取调优 | 改进主色 / 边框 / 强调色聚类与对比度策略 | 半透明皮肤、高对比装饰图仍可能偏色 |
| 布局映射校准 | 用真实样本截图对照微调 margin / spacing / hilite | 当前对过大内缩做硬回退，精细度不足 |
| 人工评分表 | 颜色、字体、方向、间距、可读性五维打分 | 建立可重复的视觉回归基准 |
| 扩充样本矩阵 | 纳入更多 ZIP / 旧式 / GBK / 色键皮肤 | 降低未知变体风险 |
| 预览对比模式 | 并排展示源皮肤截图与生成 preview | 便于 P1 调优与验收 |

## P2：产品能力扩展

| 功能 | 说明 | 动机 |
|---|---|---|
| `--all-layouts` | 一次生成横排与竖排两套配置包 | 需求 §24；当前每次只激活一种布局 |
| 批量转换目录 | `convert` 接受目录，批量处理 `.ssf` | 整理皮肤库时更高效 |
| 交互式配色选择 | 对 H1/H2/V1/V2 或多种取色结果做选择 | 复杂皮肤一键结果未必最优 |
| 安装预览 diff | `--install` 前展示将改动的 YAML 差异 | 降低用户对合并结果的顾虑 |
| GUI 拖放界面 | 图形界面拖入 `.ssf` 完成转换 / 安装 | 需求 §24；面向非命令行用户 |
| Windows ARM64 发布 | 增加 `win-arm64` 自包含产物 | 需求 §24 |

## P3：解析与格式兼容

| 功能 | 说明 | 动机 |
|---|---|---|
| 更多 `skin.ini` 字段 | 系统梳理未映射键并分级报告 | 当前未知键进入报告，但未专项建模 |
| H2/V2 双背景近似 | 对拼音区 / 候选区分离背景做更好的颜色与间距近似 | 运行时组合仍无法表达，可改善静态近似 |
| GIF 多帧报告增强 | 更详细的动画属性与预览帧选择策略 | 现仅取第一帧并警告 |
| `.sgfont` 探测 | 识别皮肤引用的搜狗字体包是否可映射到系统字体 | 工作区已有 `Fonts/` 素材，首版未处理 |
| 第三种容器变体 | 若发现新签名则插件化扩展 reader | 需求 §22 已知风险 |

## P4：安全与健壮性

首版按用户决定暂缓完整安全加固；下列项属后续版本：

| 功能 | 说明 |
|---|---|
| 资源上限与解压配额 | 防止超大 ZIP / zip bomb / 畸形偏移表耗尽内存 |
| 覆盖率引导的模糊测试 | 针对 reader 与 INI 解析器 |
| 更严格的路径与条目配额 | 在现有 `../` 拒绝之上增加数量 / 体积限制 |
| 可选沙箱隔离 | 对不可信皮肤文件的解码隔离 |

## P5：小狼毫生态（独立评估）

| 功能 | 说明 | 备注 |
|---|---|---|
| 位图背景渲染扩展 | 让小狼毫候选窗直接显示搜狗风格背景图 | 需改 Weasel 渲染器；应作为独立项目评估 |
| 状态栏 / 按钮等价物 | 搜狗状态栏、账号、简繁等按钮 | 首版明确范围外 |
| 版本兼容层 | 检测小狼毫版本并适配字段行为变化 | 需求 §22 风险项 |

## 不计划纳入本项目的方向

下列方向在需求文档中已明确排除，除非产品目标整体变更，否则不应混入本仓库：

- 修改小狼毫候选窗渲染器本体（除非拆为独立项目）
- 在线皮肤商店、下载、同步或遥测
- macOS / Linux 首发支持（当前依赖 GDI+ / Windows 路径约定）
- 像素级视觉一致性验收作为发布门槛
- 随程序分发用户提供的真实皮肤或作者联系方式

## 建议的下一步

若继续迭代，推荐顺序：

1. **P1 视觉调优**：用 `_acceptance/` 预览与源截图对照，先修颜色与边距。
2. **`--all-layouts` + 批量转换**：低成本、高实用性的 CLI 增强。
3. **安全配额**：准备公开分发前补齐。
4. **GUI**：待 CLI 行为稳定后再做。
